# Jana Address Frontend (Jana Post)

Автономный фронтенд (React 18 + TypeScript + Vite + Tailwind CSS + `lucide-react`) для нормализации, гео-обогащения и ручной верификации адресов доставки.

## Запуск

```bash
npm install
npm run dev
```

## Сборка для продакшена

```bash
npm run build
npm run preview
```
