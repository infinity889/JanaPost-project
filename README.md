# Jana Address — Система разбора и гео-обогащения адресов доставки (Jana Post)

Автономный корпоративный фронтенд (React 18 + TypeScript + Vite + Tailwind CSS + `lucide-react`) для нормализации, гео-обогащения и ручной верификации адресов доставки.

## Структура репозитория

- `frontend/` — клиентское веб-приложение **Jana Address** (React + TypeScript + Vite + Tailwind CSS).

## Быстрый старт фронтенда

```bash
cd frontend
npm install
npm run dev
```

Готовые тестовые файлы лежат в `frontend/public/`:
- `frontend/public/sample_input.json` — пример входного батча.
- `frontend/public/sample_output.json` — пример выходного файла.
